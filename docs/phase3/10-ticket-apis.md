# Ticket APIs

## Endpoints
### Create Ticket
- POST /api/v1/tickets

### Get Ticket
- GET /api/v1/tickets/{ticketId}

### List Tickets
- GET /api/v1/tickets

### Update Ticket
- PUT /api/v1/tickets/{ticketId}

## Notes
- Tickets represent customer support or operational cases linked to bookings or payments.
- Status progression should be explicit and auditable.
