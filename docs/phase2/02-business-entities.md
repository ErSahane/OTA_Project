# Business Entities

## Primary Entities
- User
- Customer Profile
- Agent Profile
- Corporate Account
- Booking
- Booking Item
- Traveler
- Passenger
- Fare Rule
- Supplier
- Supplier Product
- Payment
- Refund
- Support Ticket
- Audit Event
- Configuration Entry

## Entity Descriptions
### User
Represents an authenticated identity in the platform.

### Customer Profile
Represents a customer’s profile, preferences, and profile-level metadata.

### Booking
Represents the main reservation lifecycle and acts as the anchor for passengers, fares, and payment events.

### Booking Item
Represents one unit of travel within a booking, such as a flight segment.

### Payment
Represents an attempted, succeeded, or failed financial transaction.

### Refund
Represents financial compensation or reversal linked to a payment or booking.

### Support Ticket
Represents a case generated for customer service or operational intervention.
