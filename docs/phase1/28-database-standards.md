# Database Standards

## Objectives
Maintain data integrity, performance, and operational safety across transactional and analytical workloads.

## Standards
- Use relational databases for transactional data.
- Use indexing strategies aligned with query patterns.
- Enforce referential integrity and constraints.
- Avoid direct cross-service database access.
- Use migration-based schema evolution.

## Data Design Guidance
- Separate operational and analytical concerns where needed.
- Apply encryption and role-based access to sensitive tables.
- Maintain backup and recovery procedures.
- Keep schema changes versioned and reviewable.
