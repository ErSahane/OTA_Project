# Documentation Standards

## Objectives
Ensure all architecture, implementation, and operational documentation is consistent, discoverable, and maintainable.

## Documentation Rules
- Use Markdown for all technical documentation.
- Keep documents concise, structured, and versioned.
- Maintain a clear index for major documentation sets.
- Update documentation with design changes.
- Store architectural decisions in a central ADR location.

## Required Documentation Areas
- Architecture decisions
- Service contracts
- Deployment and runbooks
- Security and compliance notes
- Operational procedures
