# Coding Standards

## General Standards
- Write readable, maintainable, and testable code.
- Keep functions focused and small.
- Prefer explicitness over cleverness.
- Avoid hard-coded secrets and environment assumptions.
- Document public interfaces and non-obvious logic.

## Language Standards
- Follow language-specific conventions and linting rules.
- Use strong typing where available.
- Avoid unused code and dead branches.
- Handle errors explicitly and consistently.

## Architectural Standards
- Keep services independent and loosely coupled.
- Use dependency injection and abstractions for integrations.
- Favor interfaces and contracts over implicit behavior.
- Ensure idempotency for critical operations.
