# User Roles and User Journeys

## 1. User Roles
### Customer
- Searches flights
- Views offers
- Completes bookings
- Tracks and manages bookings

### Agent
- Books on behalf of clients
- Manages multiple itineraries
- Accesses commission-aware workflows

### Corporate Traveler
- Books business travel
- Uses policy-compliant travel options
- Accesses approval-based workflows

### Admin
- Manages bookings, users, and support tickets
- Monitors operational health
- Oversees policy and reporting

### Support Team
- Resolves booking issues
- Handles cancellations and refund escalations

## 2. Primary User Journey: Customer
1. User browses the homepage.
2. User searches for flights.
3. User compares available itineraries.
4. User selects a flight and proceeds to booking.
5. User enters traveler details.
6. User completes payment.
7. User receives booking confirmation and itinerary summary.

## 3. Agent Journey
1. Agent logs in to the B2B portal.
2. Agent searches for flights for a client.
3. Agent selects itinerary and enters traveler information.
4. Agent submits booking for payment and confirmation.
5. Agent monitors booking status and updates client.

## 4. Admin Journey
1. Admin signs in to admin panel.
2. Admin reviews recent bookings and exceptions.
3. Admin handles support requests or payment issues.
4. Admin updates status and communicates resolution.
