# Mobile Screens

## Mobile Experience Focus
- Search and results on the go
- Lightweight booking flow with strong form guidance
- Confirmation and itinerary access
- Support and profile management

## Key Mobile Screens
- Mobile Home
- Search Results
- Fare Selection
- Traveler Details
- Payment Review
- Confirmation
- Booking List
- Support Chat / Ticket View

## Mobile UX Principles
- One primary action per screen
- Sticky summary components for booking continuity
- Thumb-friendly controls
- Progressive disclosure for optional information
