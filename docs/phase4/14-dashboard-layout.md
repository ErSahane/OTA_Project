# Dashboard Layout

## Dashboard Structure
- Header with global navigation and user controls
- Summary cards for bookings, payments, and support items
- Quick actions for common tasks
- Recent activity list
- Status and alerts panel
- Filter and search tools for operations

## Layout Principles
- Keep important information visible above the fold on desktop.
- Group related controls into clear cards and panels.
- Use consistent spacing and hierarchy to make scanning easy.
- Present operational metrics in a calm and readable format.
