# Color Palette

## Primary Palette
- Primary Blue: #0F5BD8
- Primary Dark: #0A2F6B
- Accent Teal: #14B8A6
- Accent Orange: #F59E0B

## Neutral Palette
- Background: #F8FAFC
- Surface: #FFFFFF
- Border: #E2E8F0
- Text Primary: #0F172A
- Text Secondary: #475569
- Muted: #64748B

## Semantic Colors
- Success: #16A34A
- Warning: #D97706
- Error: #DC2626
- Info: #2563EB

## Usage Guidance
- Use blue for trust and action.
- Use teal for secondary emphasis and status.
- Use orange sparingly for highlights and warnings.
- Neutral tones support readability and calmness.
