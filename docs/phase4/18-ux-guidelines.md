# UX Guidelines

## Core UX Principles
- Guide users from intent to completion with minimal friction.
- Use clear hierarchy to reduce confusion.
- Build trust through transparency, consistency, and strong feedback.
- Make primary actions obvious and easy to reach.
- Support users with clear empty states, loading states, and errors.

## Content Guidelines
- Use concise, practical language.
- Align labels with user expectations.
- Explain policies and charges clearly before purchase.
- Provide reassurance through confirmation and tracking surfaces.

## Interaction Guidelines
- Preserve context during multi-step flows.
- Keep flow steps short and focused.
- Provide progress indicators when the journey spans several screens.
- Use consistent patterns for search, selection, and review.
