# Accessibility (WCAG)

## Target Standard
- WCAG 2.2 AA as the baseline target

## Accessibility Requirements
- Sufficient color contrast for text and controls
- Keyboard navigability for all interactive elements
- Focus indicators for all focusable elements
- Semantic headings and landmarks
- Screen-reader friendly labels and error messaging
- Support for reduced motion and zoomed layouts

## Interaction Guidance
- Avoid relying on color alone to communicate status.
- Provide clear error summaries and inline guidance.
- Ensure form fields are properly labeled and grouped.
- Keep touch targets at least 44x44 CSS px where practical.
