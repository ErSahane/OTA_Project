# Icons

## Icon Style
- Modern outline style
- Rounded corners and clean stroke weights
- Consistent 24px base size

## Recommended Icon Categories
- Navigation icons
- Travel and location icons
- Action icons
- Status and alert icons
- Support and account icons

## Usage Guidelines
- Use icons to reinforce meaning, not replace text.
- Keep icon sets consistent in weight and visual density.
- Ensure accessibility by pairing icons with labels or tooltips where necessary.
