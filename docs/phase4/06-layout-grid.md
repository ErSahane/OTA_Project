# Layout Grid

## Grid System
- 12-column grid for desktop
- 8-column grid for tablet
- 4-column grid for mobile

## Spacing Scale
- 4px
- 8px
- 12px
- 16px
- 24px
- 32px
- 48px
- 64px

## Layout Rules
- Use generous padding around primary content.
- Align card components to a predictable rhythm.
- Keep primary action areas visible without crowding the screen.
- Maintain whitespace to preserve clarity and reduce visual fatigue.
