# Typography

## Type Scale
- Display: 40px / 700
- H1: 32px / 700
- H2: 24px / 600
- H3: 20px / 600
- Body Large: 18px / 400
- Body: 16px / 400
- Caption: 14px / 400
- Small: 12px / 400

## Recommended Font Family
- Inter for UI and product experience
- Source Sans 3 for editorial or marketing support if needed

## Typography Principles
- Use clear hierarchy for scanability
- Maintain strong contrast between text and backgrounds
- Keep line length comfortable for readability
- Use weights deliberately to signal importance
