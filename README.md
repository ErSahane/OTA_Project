# AstraVoyage OTA Platform

## Project Overview
AstraVoyage is an enterprise-grade Online Travel Agency platform designed for multi-channel travel distribution, with an MVP focused on flight booking. The platform is planned for web, mobile, corporate, and B2B use cases while keeping the architecture modular and scalable for future expansion into hotels, buses, visas, and insurance.

## Product Scope
### Version 1 (MVP)
- Flight search and comparison
- One-way and round-trip booking
- Passenger details capture
- Payment initiation
- Booking confirmation
- Cancellation and refund workflows
- Admin oversight for bookings and support

### Future Phases
- Hotel booking
- Bus booking
- Visa services
- Insurance
- Corporate and B2B portals
- Native Android and iOS applications

## Architecture Direction
The solution is planned as a modular platform with:
- Frontend applications for web and mobile
- API Gateway and BFF layer
- Identity and access management
- Booking services
- Search and pricing services
- Payments and notifications
- Admin and agent portals
